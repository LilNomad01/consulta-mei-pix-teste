COMO FUNCIONA

Um processo simples, com as informações certas.

A consulta de MEI é somente o começo. A antecipação depende de vendas existentes e de uma proposta de uma instituição parceira.

01

Consulte o CNPJ

Confira a situação cadastral e a opção pelo MEI, quando os dados estiverem disponíveis.

02

Confirme as vendas

Autorize a consulta das agendas de recebíveis existentes, pelo canal do parceiro financeiro.

03

Analise a proposta

Veja valores líquidos, descontos, taxas, prazos e condições antes de decidir.

04

Receba, se aprovado

Após a contratação válida, a instituição pode realizar o pagamento pela modalidade acordada, incluindo Pix.

DÚVIDAS FREQUENTES

Informação clara em cada etapa.

Saiba o que é necessário para avaliar uma antecipação de recebíveis.

Voltar para consulta
Todo MEI ativo pode receber uma antecipação?

Não. A situação de MEI não é prova de vendas a receber. A disponibilidade depende da existência de recebíveis elegíveis, da política do parceiro financeiro e da contratação.

Como funciona o recebimento por Pix?

O Pix é um meio de transferência. Uma instituição financeira poderá utilizá-lo para pagar uma antecipação de recebíveis após validação, aprovação e contratação.

Esta consulta é um serviço do Governo Federal?

Não. Consulta MEI é uma plataforma independente que usa fontes públicas para consultar dados cadastrais. Para serviços oficiais, utilize os canais da Receita Federal.
